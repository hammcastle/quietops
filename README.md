# QuietOps GitHub Pages Package

Static deploy package prepared from `public-github-pages-copy/`.

## Deploy target
Recommended first URL: `https://hammcastle.github.io/quietops/`

## Files
- `index.html` — landing page
- `intake.html` — workflow intake page
- `assets/` — static images/assets
- `.nojekyll` — disables Jekyll processing on GitHub Pages

## Guardrails
- Do not add secrets, private network URLs, payment links, or private endpoints.
- Do not deploy/send outreach until Josh confirms URL path and exact send approval.
